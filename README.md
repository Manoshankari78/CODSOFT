📲 Task 1: Mobile App Signup Flow
This is the first project completed as part of my UI/UX Internship at CodSoft.
The design focuses on creating a seamless, secure, and user-friendly signup/login experience for a mobile application.

🎨 Features
✅ Short and easy-to-complete signup process
✅ Social login options (e.g., Google, Facebook)
✅ Personalized experience
✅ Error-free validation
✅ Secure user data handling
